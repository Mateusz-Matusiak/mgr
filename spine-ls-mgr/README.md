# spine-ls-mgr
Algorithm for lumbar spine pathologies detection.

### How to run algorithms

1. Create virtual environment - `python3 -m venv .venv`
2. Start virtual environment - `.venv/bin/activate`
3. Install required packages - `python3 -m pip install -r requrirements.txt`\
4. Run selected algorithm - e.g.: `python3 algorighms/kregomzyk.py`
